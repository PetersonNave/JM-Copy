# Checklist de Kickoff — Coleta de Materiais

**Cliente:** _______________  
**Data:** _______________

## Identidade Visual
- [ ] Logo em alta resolução (SVG ou PNG com fundo transparente)
- [ ] Paleta de cores principal (hex) — ou referência de estilo
- [ ] Fonte usada na marca (se souber)

## Conteúdo Textual
- [ ] Slogan / tagline
- [ ] Descrição da empresa (2-3 linhas)
- [ ] Lista de serviços com descrição de cada um
- [ ] Diferenciais / motivos para escolher a empresa
- [ ] Texto de cada diferencial numérico (ex: "30 anos de experiência")

## Contato e Localização
- [ ] Número do WhatsApp (com DDI+DDD)
- [ ] E-mail de contato
- [ ] Telefone fixo (se houver)
- [ ] Endereço completo (rua, número, bairro, cidade, CEP)
- [ ] Link do Google Maps
- [ ] Horário de funcionamento completo

## Fotos e Mídia
- [ ] Fotos dos trabalhos realizados (mínimo 6 para galeria)
- [ ] Foto da fachada / loja
- [ ] Foto para o hero (banner principal) — opcional
- [ ] Vídeo institucional — opcional

## Redes Sociais
- [ ] Link do Instagram
- [ ] Link do Facebook (se tiver)
- [ ] Link do YouTube (se tiver)

## Avaliações Google
- [ ] Link do Google Meu Negócio
- [ ] Nota geral e número de avaliações
- [ ] 3 avaliações em destaque para o site (copiar nome, nota e texto)

## Domínio
- [ ] Já tem domínio? Qual?
- [ ] Se não tem: definir nome do domínio (ex: empresanome.com.br)
- [ ] Quem vai registrar? (cliente ou você)
- [ ] Prazo para regularizar

## Decisões Técnicas
- [ ] O cliente vai querer editar o site sozinho? (define stack)
- [ ] Precisa de formulário de contato ou só WhatsApp?
- [ ] Google Analytics? (confirmar e-mail da conta Google do cliente)
- [ ] Meta Pixel? (confirmar acesso ao Gerenciador de Anúncios)

---

> Após coletar tudo, preencher o `src/config/site.ts` com as informações.
